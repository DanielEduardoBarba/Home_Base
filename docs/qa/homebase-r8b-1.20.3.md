### Observations (not filed)

- After an interrupted callback is delivered and the pending file is removed, a later restart does not re-list that job in `homebase_cursor_job_list` (jobs stay memory-only). The webhook is not resent.
- Settings hints for a `Bearer …` value start with `Bear` (first four characters of `Bearer`).
- `sudo homebase unlock` printed a nonsensical `lockedUntil=+058838-…` timestamp for a file whose `lockedUntil` was epoch milliseconds. The clear itself succeeded. Pre-existing display confusion, not introduced as a functional unlock failure.
- A combined `bun test test/unit` run with no worktree `web/dist` yet failed the static precompress tests. After building the worktree UI they passed. Not a product defect.
